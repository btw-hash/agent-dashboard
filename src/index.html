    1 · Claude Code on this machine

    Reads your local session logs. Nothing about the work leaves your computer: no project names, no file paths, no message text. 

    git clone https://github.com/btw-hash/agent-dashboard
cd agent-dashboard
npm install && npm run build && npm start

    2 · Any bot or script

    One request per state change. States: working, thinking, idle, done, error.

    curl -X POST http://localhost:3737/api/event \
  -H "Content-Type: application/json" \
  -d '{"agent":"my-bot","state":"working","note":"crunching"}'
